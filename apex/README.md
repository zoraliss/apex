# Apex · Service Lane Coordination

## How to deploy to Vercel

1. Go to github.com and create a new repository called `apex`
2. Upload all these files — drag and drop the whole folder
3. Go to vercel.com, click "Add New Project"
4. Select your GitHub repo `apex`
5. Click Deploy — no settings needed to change
6. Vercel gives you a live URL like `apex-yourname.vercel.app`
7. Share that link with your team — they open it on any phone

## How to use

- Each person creates their own account with email + password
- Their name automatically appears on the porter board
- Set your status using the buttons on the Board tab
- Create runs in the New tab — they appear live for everyone instantly
- Tap any run in the Runs tab to open navigation
- Use the Comms tab for team messages

## Notes

- SMS is disabled — internal test mode only
- All data syncs in real time across all phones
- Works on any phone browser, no app store needed
- Can be saved to home screen: tap Share → Add to Home Screen

## Files

- index.html — main app
- css/style.css — all styling
- js/app.js — all logic + Firebase connection
